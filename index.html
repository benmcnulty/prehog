What does this page measure?

Six custom events, plus PostHog's standard pageview. Full spec: docs/analytics.md.

  • prehog_slide_viewed — which sections hold attention, deduplicated per session.
  • prehog_navigation_used — whether controls are discoverable, especially on mobile.
  • prehog_autoplay_toggled — whether anyone lets the deck run itself or takes control.
  • prehog_measurement_panel_opened — you opening this exact panel.
  • prehog_outbound_clicked — which evidence links and CTAs get followed.
  • prehog_completed — whether the deck gets finished.

Deliberately not collected: names, emails, precise location, or any cross-site identity. Session replay is on for this page only, with every form input masked — including the optional survey's rating and free-text answer, which replay never shows even though the event data does.
